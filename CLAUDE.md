# Working conventions for this repo

- After finishing a set of edits the user asked for, commit and push to `main` automatically — do not stop to ask for push confirmation first. This repo is a personal portfolio (`Atikul-Dipto.github.io`) deployed via GitHub Actions (`.github/workflows/deploy.yml`) on every push to `main`, so pushing just updates the live site. Still use good commit messages and never force-push or rewrite history without asking.
